# Environment Variables

The app needs none at runtime. All of these are optional.

| Variable                             | Kind                              | Read in                                                     | Purpose                                                                                         |
| ------------------------------------ | --------------------------------- | ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `REPOTRAY_GITHUB_CLIENT_ID`          | compile-time (Rust `option_env!`) | `src-tauri/src/browser_auth.rs`                             | Public Client ID of the publisher GitHub App for device-flow sign-in (sign-in currently paused) |
| `REPOTRAY_GITHUB_APP_SLUG`           | compile-time                      | `src-tauri/src/browser_auth.rs`                             | App slug for the installation page link                                                         |
| `REPOTRAY_UPDATER_PUBLIC_KEY`        | compile-time / script             | `src-tauri/src/desktop_updates.rs`, `scripts/updater.mjs`   | Tauri updater public key for separately signed builds; unset in the standard unsigned release   |
| `GH_CONFIG_DIR`                      | runtime (honored)                 | `src-tauri/src/local_auth.rs`                               | Explicit absolute gh config dir for local gh discovery                                          |
| `PLAYWRIGHT_CHROMIUM_EXECUTABLE`     | test                              | `playwright.config.ts`, `scripts/capture-*.mjs`             | Use a preinstalled Chromium                                                                     |
| `POWERSHELL_EXECUTABLE`              | test                              | `scripts/release-workflow.test.mjs`                         | PowerShell 7 binary for the workflow tests                                                      |
| `CI`                                 | test                              | `playwright.config.ts`, `scripts/release-workflow.test.mjs` | Forbid `.only`, one retry, no server reuse; PowerShell tests mandatory                          |
| `REVIEW_BASE_URL`, `CARD_REVIEW_DIR` | script                            | `scripts/capture-*.mjs`                                     | Screenshot capture target / output dir (`docs/review/`, gitignored)                             |

## Secrets Locations

No secret is needed to build or test. Runtime GitHub tokens live only in the OS credential vault under RepoTray's own namespaces (`github-<id>`, `github-gh-<id>`, `github-device-<id>`). The release workflow uses only the repository `GITHUB_TOKEN`. Fixtures and captures are synthetic. No `.env` file is used.
