# Changelog

## [0.1.0] - 2026-10-31

- Windows tray panel for current GitHub Actions, selected repositories and saved workflow templates.
- Native token sign-in with account verification and OS credential-store persistence; no plaintext token cache.
- Typed workflow inputs, branch/tag selection, explicit quick-start opt-in and persistent protection after uncertain starts.
- Compact activity and launch views, account context, offline cache and GitHub links.
- Private authenticated release discovery and changelog, with an unsigned Windows EXE downloaded in the browser for manual installation.
- Browser login still requires a separately registered GitHub App. Browser previews use clearly labelled local fixtures.
