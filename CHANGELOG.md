# Changelog

Release notes live on the [GitHub Releases page](https://github.com/fo0/repo-tray/releases), which is the changelog of record. Each release uses a CalVer version (`YYYY.MMDD.HHmm`, UTC) and GitHub-generated notes from the merged changes; see [release process](docs/RELEASES.md). This file is not updated per release.

## [0.1.0] - 2026-10-31 (historical)

The initial development version before CalVer releases. Kept for history only; current behavior is described in the [README](README.md) and [docs](docs/).

- Windows tray panel for current GitHub Actions, selected repositories and saved workflow templates.
- Native token sign-in with account verification and OS credential-store persistence; no plaintext token cache.
- Typed workflow inputs, branch/tag selection, explicit quick-start opt-in and persistent protection after uncertain starts.
- Compact activity and launch views, account context, offline cache and GitHub links.
